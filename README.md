# Motorola SM6150 - Device Configuration for LineageOS

📱 **This repository provides device configuration for Motorola smartphones powered by the Qualcomm Snapdragon 730G (SM6150) chipset.**  
Based on contributions from the LineageOS community.

| Moto G Stylus (2021)   | minsk    | 10                       |
| Moto G60               | hanoip   | 11                       |
